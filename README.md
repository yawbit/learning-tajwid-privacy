# Yawbit privacy pages

Privacy policies for Yawbit's Android apps, hosted with GitHub Pages from `main` at `/`.

| Page | Link for Play Console |
|---|---|
| Learning Tajwid privacy | https://yawbit.github.io/privacy/learning-tajwid/ |
| Daily Schedule privacy | https://yawbit.github.io/privacy/daily-schedule/ |
| Daily Schedule account deletion | https://yawbit.github.io/privacy/daily-schedule/delete-account/ |

## Rules

- The text inside `<pre>` must stay word for word the same as the policy bundled in the app
  (`assets/legal/privacy.en.txt` in `Quranic_Sciences` and `muslim_schedule`) and the copy on
  yawbit.com (`yawbit-website/src/content/legal/`). Change all three together.
- Update the "Effective" date whenever the policy changes.
- Firdos policies live separately in `mtecho/firdos-privacy`.
