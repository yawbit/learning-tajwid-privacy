# Learning Tajwid privacy policy

Privacy policy for the Learning Tajwid Android app (`com.yawbit.learningtajwid`) by Yawbit,
hosted with GitHub Pages from `main` at `/`.

Play Console privacy link: https://yawbit.github.io/learning-tajwid-privacy/

Learning Tajwid has no user accounts, so no account-deletion page is needed.

## Rules

- The text inside `<pre>` in `index.html` must stay word for word the same as the policy
  bundled in the app (`Quranic_Sciences/assets/legal/privacy.en.txt`) and the copy on
  yawbit.com (`yawbit-website/src/content/legal/learning-tajwid.txt`). Change all three together.
- Update the "Effective" date whenever the policy changes.
